# EcoLearn

EcoLearn is a personalized AI tutoring system that adapts environmental and sustainability education to each learner's unique interests and pace. Powered by Google's Gemini, it uses a multi-agent architecture to understand what a student cares about, map that to a structured curriculum, and deliver lessons, quizzes, and feedback in a conversational interface built with Streamlit — so learning about ecology, climate, and sustainability always feels relevant and engaging.
