Our agent system

AI agents that help, and rules wherever a student is judged

Every AI agent has a safe non-AI fallback. Marking, mastery and the learning path are rules, so no AI ever grades a student.

About a minute. This is the agent system around a student, and we are clear about which parts are AI. On the left, three AI agents for the student: a story writer with a critic that checks it, a doubt chat that answers from the student’s own lesson, and practice questions written by one AI and solved independently by another before a student sees them. On the right, the parts that judge or track a student: their profile, their learning path, the graded checks and mastery. These are rules on purpose, so the same answers always get the same result and no AI marks anyone. At the bottom, two AI agents for the teacher: a teaching assistant that plans the next lesson from class data, with students shown only as S1, S2, and a coaching agent that suggests one action per student, which the teacher approves before anything happens.
