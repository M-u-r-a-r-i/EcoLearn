# Case-study deck: "EcoLearn: Aarav's journey"

A second, separate deck (made 2026-10-28) that follows one sample student through the product, then shows India's numbers.
It lives as a private Claude artifact (Slides type): https://claude.ai/artifact/JZG5D1bKfjxnDgv4zf9kKB (31 slides, white
background, speaker notes in each). Its interactive companion page (Chart.js charts with tooltips, an urban/rural toggle and a
value calculator) is https://claude.ai/artifact/Cs7sgMvmG2hAKUcLqz6uS7; slides "india" and "value" link to it.
Both are private until the user shares them from the page's Share menu.

- `deck.json` + `slides/*.html`: the deck's own files in the Slides type's format. Images are `/_blob/<id>` assets stored in that
  artifact (the 14 cropped screenshots); they are not in this folder.
- `india-numbers.html`: the companion page's source.
- `capture/shoot.py`: how the screenshots were taken: headless Edge over the DevTools protocol, logging in as demo accounts against
  a web server on :3100 and an API on :8100 that ran on a COPY of `data/demo.db` (from a throwaway worktree, with
  `http://localhost:3100` added to the CORS list there only). Steps are JSON files: `{"login": "aarav.k"}`, `{"go": "/roadmap"}`,
  `{"js": "..."}`, `{"shot": "name", "full": true}`.

Honesty rules the deck follows: Aarav and his class are the demo dataset (fictional); every screenshot says "sample student" or
"sample class". The personal story, the doubt-chat answer and the teaching-assistant plan are REAL AI outputs (Gemini 3.1
Flash-Lite via OmniRoute, 28 Oct 2026). In the copy, `ananya.r` played Aarav for the first-sign-in screens (survey, starting
check); the class numbers on the teacher screens are invented demo data.

India figures (checked 2026-10-28): UDISE+ higher secondary enrolment 2.86 / 2.78 / 2.71 / 2.76 / 2.89 crore (2021-22 to
2025-26, via educationforallinindia.com analyses, not the official tables); NEET UG 2025 22.76 lakh registered; JEE Main 2025
15,39,848 unique registered; CBSE Class 12 2025 16,92,794 appeared; NSS CMS:E 2025 higher secondary coaching 44.6% urban / 33.1%
rural, Rs 9,950 / Rs 4,548 a year; ASER 2024 (rural, 14-16): ~90% smartphone at home, 82.2% can use one, own one 36.2% boys /
26.9% girls. The Rs 100 a month price and the Rs 63 per student-year AI cost (`scripts/adaptive_cost_model.py`, scenario A) are
assumptions and estimates, labelled as such on the slides.

Results section (slides `results`, `gain`, `studied`, `concepts`, `confidence`, `pilot`, added 2026-10-28): every number comes from
`get_class_checks` / `get_class_insights` on a COPY of `data/demo.db`, the SIMULATED class (answers generated by
`scripts/seed_demo.py`, then graded by the real app), and every slide says "simulated, not pilot results". Never present them as
outcomes. The last one bridges to the pre-registered pilot (`docs/pilot-experiment.md`).
